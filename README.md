# NOT-Volga

> Приложение с открытым исходным кодом для использования в автобусах Твери.

Разработано на Flutter. Имеет минимальную серверную часть, которая используется только для получения актуальных цен.

## Архитектура

### Серверная часть

- Реализована в виде обновляемого JSON-файла.
- Деплой осуществляется через RAW GitHub (raw.githubusercontent.com).

### Клиентская часть

- Готовое автономное приложение, полностью повторяющее интерфейс приложения «Волга».
- При запуске приложение пытается обратиться к серверу (RAW GitHub):
  - если соединение успешно — цены обновляются из JSON-файла;
  - если интернет недоступен — используются последние сохранённые в памяти приложения цены.

## Возможности

1. Интерфейс, идентичный приложению «Волга».
2. Имитация пополнения баланса.
3. Сканирование QR-кода и покупка билета.
4. Создание собственного билета.
