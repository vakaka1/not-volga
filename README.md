# NOT-Volga

> Приложение с открытым исходным кодом для использования в автобусах Твери и Тверской области.

Разработано на Flutter. Имеет минимальную серверную часть, которая используется для получения актуальных цен.

## Архитектура

### Серверная часть

- **Данные тарифов:** Хранятся в структурированном файле [`server/tariffs.json`](file:///home/valdis/not-volga/server/tariffs.json).
- **Поддерживаемые регионы Верхневолжья:**
  1. Тверь и Калининский район
  2. Ржев и Ржевский район
  3. Старица и Старицкий район
  4. Кимры и Кимрский район
  5. Зубцов и Зубцовский район
  6. Конаково и Конаковский район
- **Парсер актуализации:** Скрипт [`server/update_tariffs.py`](file:///home/valdis/not-volga/server/update_tariffs.py) загружает и валидирует тарифы напрямую с официального портала [tvercard.ru/tarify](https://tvercard.ru/tarify/).
- **Автоматизация:** GitHub Actions workflow [`.github/workflows/update-tariffs.yml`](file:///home/valdis/not-volga/.github/workflows/update-tariffs.yml) запускается по расписанию (раз в неделю) и по кнопке `workflow_dispatch`, автоматически обновляя `tariffs.json` при изменении цен.
- **Деплой и доставка:** Осуществляется через RAW GitHub (`raw.githubusercontent.com`) или быстрый CDN (jsDelivr / Statically).

### Клиентская часть

- Готовое автономное приложение на Flutter, полностью повторяющее интерфейс приложения «Волга».
- При запуске приложение пытается обратиться к серверу (RAW GitHub / CDN):
  - если соединение успешно — цены обновляются из JSON-файла в локальное хранилище;
  - если интернет недоступен — используются последние сохранённые цены (или зашитый fallback из `assets/data/tariffs.json`).

## Возможности

1. Интерфейс, идентичный приложению «Волга».
2. Поддержка актуальных тарифов для всех городов Тверской области.
3. Имитация пополнения баланса.
4. Сканирование QR-кода и покупка билета.
5. Создание собственного билета.
