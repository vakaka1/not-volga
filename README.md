# НЕ-Волга

> Клиент с открытым исходным кодом и генератор билетов для транспорта Твери и Тверской области («Транспорт Верхневолжья»).

Разработано на Flutter. Приложение работает напрямую с **официальным API «Транспорт Верхневолжья» (Merlin API)** без использования промежуточных серверов.

---

## Архитектура

- **Прямое взаимодействие с официальным API:**  
  Все данные (города, тарифы, маршруты, остановки, треки маршрутов, геолокация автобусов в реальном времени и BLE-маяки) запрашиваются напрямую из официального шлюза:  
  `https://api.merlin.tvercard.ru/api/client/v1/`
- **Автономность и оффлайн-режим:**  
  - При наличии интернет-соединения приложение загружает свежие тарифы, маршруты и остановки напрямую из API.
  - При отсутствии сети или сбоях связи приложение использует кэшированные данные или локальный fallback из `assets/data/tariffs.json`.
- **Полная документация API:**  
  Подробное описание всех эндпоинтов, параметров и структур ответов вынесено в отдельный документ: [`API.md`](API.md).

---

## Возможности

1. **Интерфейс «Волга»:** Полностью повторяет внешний вид и сценарии оригинального приложения.
2. **Официальные тарифы и маршруты:** Получение актуальной стоимости проезда, списка остановок и маршрутов для всех городов Тверской области (Тверь, Ржев, Осташков, Пено, Кимры, Старица, Зубцов, Конаково).
3. **Онлайн-транспорт:** Мониторинг перемещения автобусов в реальном времени с отображением на карте.
4. **Определение QR:** Поддержка сканирования QR-кодов в салоне автобуса.
5. **Генерация и эмуляция билетов:** Создание билета и имитация пополнения баланса.

## Документация API

Спецификация всех маршрутов официального API находится в файле [**`API.md`**](API.md):
- `GET /locations` — список обслуживаемых зон/городов;
- `GET /tariffs` — тарифная сетка (нал/безнал в копейках);
- `GET /routes` и `GET /routes/{id}` — список и состав маршрутов;
- `GET /routes/{id}/path` — геометрия трека маршрута (полилиния);
- `GET /stations` и `GET /stations/{id}/routes` — остановки и прогноз прибытия;
- `GET /vehicles` — онлайн телеметрия и координаты автобусов;

## Сборка и запуск

1. Убедитесь, что установлен [Flutter SDK](https://flutter.dev/docs/get-started/install).
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/vakaka1/not-volga.git
   cd not-volga
   ```
3. Установите зависимости:
   ```bash
   flutter pub get
   ```
4. Запустите проект:
   ```bash
   flutter run
   ```
Для сборки APK и установки через ADB:

Сборка:
```bash
flutter build apk --release
```
Узнать ID устройства:
```bash
flutter devices
```
Установка:
```bash
adb -s ID-УСТРОЙСТВА install -r build/app/outputs/flutter-apk/app-release.apk
```
